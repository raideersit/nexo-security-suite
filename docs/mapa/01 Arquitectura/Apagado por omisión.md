# Apagado por omisión

Las funciones que vigilan o hacen copias nacen **apagadas** y solo se encienden editando `appsettings.json`, que está en `Program Files\Nexo\service` (solo escriben administradores). El pipe no tiene métodos para encenderlas, apagarlas ni cambiar sus carpetas o destinos: un proceso malicioso del usuario los usaría para desactivar la protección.
