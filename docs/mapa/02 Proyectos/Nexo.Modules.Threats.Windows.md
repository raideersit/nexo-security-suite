# Nexo.Modules.Threats.Windows

Las implementaciones reales para Windows de lo que define `Nexo.Modules.Threats`: almacén del Firewall, fuente de bloqueos, AMSI, ETW de comportamiento, WireGuard, WinGet, Wi‑Fi, cuentas, dispositivos, señuelos, carpetas protegidas, diario USN y protección de la carpeta de copias.

**Tamaño:** 16 archivos, ~1 750 líneas.
