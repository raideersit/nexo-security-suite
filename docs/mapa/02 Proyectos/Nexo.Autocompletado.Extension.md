# Nexo.Autocompletado.Extension

La extensión del navegador (JavaScript, sin compilar): `fondo.js` (service worker), `nucleo.js`, `rellenar.js` (rellena campos), `ventana.html/js/css` (el panel). Se carga descomprimida desde `Program Files\Nexo\extension`.

**Tamaño:** JavaScript + manifest.
