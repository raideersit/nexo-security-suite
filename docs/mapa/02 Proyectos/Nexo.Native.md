# Nexo.Native

Capa fina de llamadas nativas a Windows (P/Invoke): diario USN, números de archivo, política de auditoría, cuentas locales, firma de archivos (Authenticode), notificaciones y ventana activa, AMSI, Wi‑Fi (WLAN), tabla TCP, consultas de almacenamiento y estado de energía.

**Tamaño:** 14 archivos, ~1 360 líneas.
