# Nexo.Ui.Tray

La bandeja del sistema (WinForms): icono con estado, avisos globo, menú rápido y, sobre todo, el único ejecutable que se **eleva con UAC** para aplicar planes ya aprobados (`--aplicar <tipo> <token> --pipe <nombre>`).

**Tamaño:** 11 archivos, ~1 500 líneas.

## Depende de
- [Nexo.Ipc](Nexo.Ipc.md)

## Lo usan
- Es un ejecutable o paquete final: nadie lo referencia.
