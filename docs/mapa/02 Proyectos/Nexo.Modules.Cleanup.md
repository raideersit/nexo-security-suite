# Nexo.Modules.Cleanup

Limpieza y mantenimiento: archivos basura (catálogo de reglas), duplicados por contenido, triturador de archivos, inicio de Windows, salud del disco (S.M.A.R.T.), perfiles de actividad y las comprobaciones de seguridad de rutas (`GuardiaDeRutas`, `TokenConfirmacion`).

**Tamaño:** 32 archivos, ~4 000 líneas.
